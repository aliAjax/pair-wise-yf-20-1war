# hxyfront-62008 烟花燃放脚本编排 · 配乐改版台

联排后配乐从 **03:40（220s）** 切到 **04:20（260s）**，编排师逐条改点火时刻。
本页面是一个纯前端的「配乐改版台」：预置三段节目、四个点位、八枚烟花，
切换新版曲目后自动按锚点比例重排，并通过安全闸门校验。

## 改版规则

- **未锁定段落**：首尾锚点按全曲首尾锚点（0 → 新曲长）等比例重排；段内点火节点保持段内相对位置。
- **锁定段落**：锚点与时刻原样保留。
- **应用闸门**：候选版本出现以下任一问题即停止应用、保留上一版，并列出全部问题：
  1. 冷却不足 —— 同一点位两次点火间隔短于前一枚烟花的冷却时间；
  2. 危险区相交 —— 两枚烟花燃烧窗口相交，且点位距离小于两者安全半径之和；
  3. 节点越出段落 —— 点火时刻或燃烧结束越过所属段落的首尾锚点 / 曲目范围。
- 默认全不锁时切换可通过；锁定「Chorus 主歌」后再切 04:20，可看到冷却闸门拦截。
- 时间轴、点位平面图、型号用量随编辑与版本切换实时更新；数据保存在浏览器
  localStorage，重开页面仍可编辑，无后端。

## 代码分层（数据 / 规则 / 交互分开维护）

```
src/
├── data/            # 数据层：类型、预置目录（曲目/点位/型号/初始节目）、localStorage
│   ├── types.ts
│   ├── presets.ts
│   └── storage.ts
├── rules/           # 规则层：纯函数，可独立单测，不依赖 React
│   ├── time.ts      #   时间码 mm:ss.mmm
│   ├── remap.ts     #   首尾锚点比例重排
│   └── validate.ts  #   冷却 / 危险区 / 越界闸门
├── state/
│   └── useShow.ts   # 交互层：状态机（改版闸门、持久化、编辑操作）
├── components/      # 交互层：版本台、时间轴、点位图、段落锁、节点编辑、冲突提示、用量
└── App.tsx
```
