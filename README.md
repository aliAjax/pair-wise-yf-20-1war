# hxyfront-62008 烟花燃放配乐改版台

源提示词编号：10

面向烟花燃放编排师的配乐改版工具。联排后配乐从 3′40″ 切到 4′20″，编排师可在页面上逐条调整点火时刻，也可以一键切换曲目版本：

- 预置三段节目（开场 / 主歌 / 终章）、四个燃放点位、八枚点火节点、四种烟花型号
- 切换新版曲目时，未锁定段落按首尾锚点比例重排，锁定段落留在原时刻
- 安全规则：冷却不足、危险区相交、节点越出段落，任一命中即停止应用并保留上一版
- 时间轴、点位图、型号用量随草稿同步更新
- 草稿保存在 localStorage，不新增后端，重开页面仍可继续编辑

## 目录结构（数据 / 规则 / 交互分离）

```
src/
  data/showData.ts        数据层：预置版本、段落、点位、型号、节点（纯数据）
  rules/replan.ts         规则层：比例重排 + 三类安全校验（纯函数）
  state/useShowStore.ts   状态层：草稿状态、动作与 localStorage 持久化
  components/             视图：改版台 / 时间轴 / 点位图 / 型号用量 / 节点表
  App.tsx                 页面组装
```

## 技术栈

React + Vite + TypeScript
